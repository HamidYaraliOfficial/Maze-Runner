Maze Runner - بازی دونده‌ی هزارتو
نسخه‌ی اول (ساده)
بازی Maze Runner یک بازی تعاملی هزارتو است که با استفاده از الگوریتم DFS، هزارتوهای تصادفی و منحصربه‌فرد تولید می‌کند. شما باید با استفاده از کلیدهای جهت‌دار (↑ ↓ ← →) یا دکمه‌های روی صفحه، گنج پنهان در هزارتو را پیدا کنید. هر حرکت سالم ۱ امتیاز، برخورد با دیوار ۱- امتیاز و پیدا کردن گنج ۱۰+ امتیاز برای شما به ارمغان می‌آورد. این بازی با بیش از ۱۰۰۰ خط کد، دارای رابط کاربری زیبا، واکنش‌گرا و زمان‌سنج است و تجربه‌ای سرگرم‌کننده و چالش‌برانگیز را برای شما فراهم می‌کند.

Maze Runner Pro - نسخه‌ی حرفه‌ای با تحلیل مسیر
Maze Runner Pro نسخه‌ی پیشرفته‌ی بازی Maze Runner است که با بیش از ۱۲۰۰ خط کد، قابلیت‌های تحلیلی قدرتمندی را اضافه کرده است. این نسخه با استفاده از الگوریتم BFS، کوتاه‌ترین مسیر ممکن به گنج را محاسبه کرده و مسیر شما را با آن مقایسه می‌کند. پنل تحلیل پیشرفته، امتیاز کارایی شما را بر اساس درصد تطابق با بهترین مسیر نمایش می‌دهد (سبز: عالی، زرد: خوب، قرمز: نیاز به بهبود). با کلیک روی دکمه یا کلید B می‌توانید بهترین مسیر را به صورت بصری روی بوم مشاهده کنید. این نسخه همچنین مسیر کامل طی‌شده توسط شما را ذخیره کرده و اختلاف آن با بهترین مسیر را نشان می‌دهد. تمام این قابلیت‌ها در کنار رابط کاربری زیبا و واکنش‌گرا، تجربه‌ای حرفه‌ای و آموزشی را برای علاقه‌مندان به بازی و الگوریتم‌های مسیریابی فراهم می‌کند.
